# Ethicarch blog

Blog website of [Ethicarch](https://ethicalarchitect.fr/)

## Setup

After installing dependencies, start the development server on `http://localhost:3000`:

```bash
# npm
npm install
npm run dev
npm run preview

# npx nuxi@latest module add tailwindcss
# npm install nuxt-i18n-micro
```
